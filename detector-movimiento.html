📹 Cámara de seguridad inteligente

Un detector de movimiento hecho con un ordenador, Python y OpenCV

← Volver a El Taller

En este proyecto convertimos el ordenador en un sencillo sistema de vigilancia. La cámara muestra la habitación, OpenCV analiza la imagen y, cuando detecta movimiento, dibuja un recuadro sobre la zona y activa un aviso sonoro.

Python OpenCV Windows Sin Arduino
⬇ Descargar detector.py

🧰 Qué necesitas

  • Un ordenador con Windows.
  • Una webcam USB o una cámara compatible con el modo Webcam, como la DJI Osmo Action 4.
  • Un cable USB de datos.
  • Python 3 instalado.
  • Conexión a Internet para instalar OpenCV.

No hacen falta Arduino, sensores de movimiento ni componentes electrónicos adicionales.

⚙️ 1. Conecta la cámara

  1. Conecta la cámara al ordenador mediante USB.
  2. En la cámara, selecciona el modo Webcam si está disponible.
  3. Comprueba que Windows la reconoce abriendo la aplicación Cámara.
  4. Cierra la aplicación Cámara antes de iniciar el detector, para que Python pueda usar el dispositivo.

🐍 2. Instala Python y OpenCV

Abre el CMD de Windows y comprueba que Python está instalado:

py --version

Después instala OpenCV:

py -m pip install opencv-python

📁 3. Prepara la carpeta

  1. Crea una carpeta llamada DetectorMovimiento en el Escritorio.
  2. Descarga el archivo detector.py desde el botón de esta página.
  3. Guarda el archivo dentro de esa carpeta.

▶️ 4. Ejecuta el detector

Abre CMD y escribe estos comandos, uno después del otro:

cd "%USERPROFILE%\\Desktop\\DetectorMovimiento"
py detector.py

Si tu Escritorio está sincronizado con OneDrive, la carpeta podría estar en %USERPROFILE%\\OneDrive\\Desktop\\DetectorMovimiento.

Se abrirá una ventana con la imagen de la cámara. Pulsa la tecla Q para cerrar el programa.

🧠 ¿Cómo funciona?

  • OpenCV captura continuamente imágenes de la cámara.
  • El programa compara los cambios entre imágenes para localizar movimiento.
  • Si el movimiento supera el umbral configurado, dibuja un recuadro rojo.
  • El ordenador emite un pitido para avisar.
Importante: es un proyecto educativo y experimental, no un sistema de alarma profesional. Puede detectar cambios de luz o movimientos de objetos y no sustituye a un sistema de seguridad certificado. Usa la cámara respetando la privacidad de las personas.
